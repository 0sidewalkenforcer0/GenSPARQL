GenSPARQL · live demo

Open-world generation, closed-world validity — in one query

GenSPARQL extends SPARQL 1.1 with two operators: GENOP calls an LLM during query evaluation and binds what it generates to query variables, and a type-aware similarity join grounds generated entities to real knowledge-graph nodes. Explore the three query shapes below over a 2026 FIFA World Cup KG built from Wikidata.
